Inbound Presence

1. LinkedIn Profile Optimization

Recruiter Index Optimization

Sourcers source candidates directly using LinkedIn Recruiter keywords. Your profile is search real estate—optimize for search indices, not just visual design.

Headline Indexing Formula

Avoid generic titles like 'Engineer at X'. Use the indexing formula:
Role Title | Core Stack Keywords | Quantifiable Value Proposition

3 Sourcing Hacks

1. Enable 'Open to Work' in Recruiter-Only mode.
2. Pin your top 3 target skills (endorsements rank higher in search filters).
3. Set a clean, short custom URL path.

LinkedIn Skill Block

Direct outreach message drafts and summary builders are compiled locally from your workspace:

/job-linkedin summary
E2E Automation

2. The Local CLI Orchestrator

Dynamic Interview Chat

Conducts a conversational AI interview, using Google STAR/XYZ metrics to extract achievements and write `profile.json`.

Parallel API Board Scanning

Concurrently queries Greenhouse/Lever boards, matching roles to profile qualifications using a single, low-latency batched prompt.

Tectonic XeLaTeX Compilation

Customizes resume bullets for job description keywords and compiles a professional PDF locally using Tectonic compiler.

Synergy Overview

3. Autofill Extensions vs. Content Tailoring

Feature Autofill Extensions (e.g. Simplify) Content Tailoring (job-search)
Focus Area Form inputs (Name, Email, History fields) Deep qualifications tailoring
Document Assembly Uploads a static, pre-existing PDF resume Rewrites bullets per JD and compiles custom XeLaTeX PDF
Interactive Prompts None Conversational STAR/XYZ interviewer
Integration Perfect Synergy: job-search compiles tailored PDF -> Simplify auto-fills & uploads

Browser Filling

To complete the pipeline, Playwright Headed browser filler navigates to the application, auto-fills inputs, uploads the tailored PDF, and pauses for review:

4. Helper Web Prompts (No-CLI Users)

Universal Compatibility

No command line configuration required. Use ChatGPT, Claude, or Copilot web interfaces directly with standard templates.

Experience Rewriter Prompt

Injects job description text and base profile into web interfaces, instructing the LLM to output custom markdown achievements.

Outbound Execution

5. Apollo Sourcing & Cold Outreach

Apollo.io Chrome Extension

Extract direct company email addresses and phone numbers of recruiters and engineering managers directly from LinkedIn company profiles.

Recruiter Outreach Strategy

Bypass job portals. Send a short, highly tailored cold email referencing that you applied and attaching the customized PDF compiled by your CLI tool.

Short Connection Note

Send connection request notes under 300 characters to peer engineers to build rapport and discover internal referrals.

Cold Email Draft

"Hi [Name], I recently applied for [Role]. I led the rewrite of [System] which cut response times by 30%—aligning directly with your requirement for [Skill]. Resumed attached. Best, [Name]"
